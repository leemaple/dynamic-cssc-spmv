# ADR 0001: Project scope

- Status: Accepted
- Date: 2026-08-21

The project targets a normal SCI/SCIE or EI paper, not a top-tier cryptography paper. The first implementation uses OpenFHE BFV, a semi-honest cloud, fixed matrix dimensions, client-assisted maintenance, public or client-shared structure according to the frozen leakage mode, and no bootstrapping, GPU, malicious security, ORAM, GNN, RAG, or federated-learning integration.
